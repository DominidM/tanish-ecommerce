### Cómo agregar evidencia

1. Crear subdirectorio del sprint si no existe
2. Guardar outputs de comandos, screenshots, configs
3. Nombrar archivos descriptivamente
4. Referenciar desde el SPRINT-XX correspondiente

### No inventar evidencia

- Solo referenciar evidencia realmente generada
- Si falta algo, marcar como [PENDIENTE]
- Los screenshots serán agregados por el usuario
