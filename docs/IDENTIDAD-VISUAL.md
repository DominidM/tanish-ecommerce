# Guía de Identidad Visual — TANISH E-Commerce

**"Compra fácil, rápida y directa."**

TANISH es una plataforma de comercio electrónico B2C orientada inicialmente a bebidas, abarrotes y productos de consumo masivo. La identidad debe transmitir **confianza, rapidez, cercanía, simplicidad y modernidad**.

---

## Paleta oficial

### Verde principal — `#22C55E`

Representa confianza, crecimiento, disponibilidad y acción.

Utilizar principalmente en:

- Botones de acción principal.
- Botón "Comprar por WhatsApp".
- Estados positivos.
- Indicadores de producto disponible.
- Enlaces o elementos interactivos importantes.
- Iconos activos.
- Elementos destacados de la marca.
- Confirmaciones y mensajes de éxito.

No utilizarlo excesivamente como fondo de grandes áreas. Debe funcionar principalmente como color de acción y reconocimiento de marca.

### Azul sólido — `#0F3B5F`

Representa seguridad, profesionalismo, estabilidad y confianza.

Utilizar en:

- Navbar y elementos principales de navegación.
- Sidebar del panel administrativo.
- Títulos y encabezados importantes.
- Botones secundarios.
- Elementos estructurales.
- Footer.
- Iconos institucionales.
- Elementos relacionados con administración, inventario y gestión.

Debe ser el principal color estructural del sistema.

### Amarillo de acento — `#FBBF24`

Representa rapidez, energía, dinamismo y atención.

Utilizar de forma moderada en:

- Promociones.
- Ofertas.
- Descuentos.
- Badges.
- Stock bajo.
- Advertencias no críticas.
- Precios o información comercial que necesite destacar.
- Botones alternativos como "Consultar disponibilidad".

No utilizar como color predominante.

### Fondo claro — `#F8F9F4`

Representa limpieza, simplicidad y amplitud.

Utilizar como:

- Fondo general de la aplicación.
- Fondo de páginas.
- Secciones secundarias.
- Formularios.
- Áreas alrededor de tarjetas.
- Superficies donde sea necesario separar visualmente contenido.

Las tarjetas pueden utilizar blanco (`#FFFFFF`) sobre este fondo para crear profundidad de manera sutil.

### Gris de apoyo — `#6B7280`

Utilizar para información secundaria y elementos con menor jerarquía.

Aplicaciones:

- Descripciones.
- Subtítulos.
- Placeholders.
- Información auxiliar.
- Iconos inactivos.
- Bordes.
- Separadores.
- Estados deshabilitados.

### Gris oscuro — `#1F2937`

Utilizar principalmente para:

- Texto principal.
- Títulos.
- Precios.
- Información importante.
- Iconos que necesiten alto contraste.

Debe garantizar una lectura clara sobre fondos blancos o claros.

---

## Jerarquía visual

La distribución aproximada de color debe mantener una interfaz limpia:

- **60%:** blanco y `#F8F9F4`
- **20%:** azul `#0F3B5F`
- **10–15%:** verde `#22C55E`
- **5%:** amarillo `#FBBF24`
- Grises utilizados según necesidades de texto, bordes y elementos secundarios

El verde y amarillo deben funcionar como colores estratégicos de acción y atención, no como colores utilizados indiscriminadamente.

## Componentes

### Navbar

Fondo blanco o azul según contexto. Logotipo TANISH visible. Verde reservado para acciones principales.

### Sidebar administrativo

Fondo principal azul `#0F3B5F`. Estados activos resaltados con verde `#22C55E`.

### Botón principal

Fondo verde `#22C55E`, texto blanco. Hover: verde ligeramente más oscuro (`#16A34A`).

### Botón secundario

Azul `#0F3B5F` con texto blanco. Hover: azul ligeramente más oscuro.

### Botón de consulta o promoción

Amarillo `#FBBF24` con texto oscuro `#1F2937` para conservar contraste.

### Cards de productos

Fondo blanco, bordes suaves, sombras discretas. Predominio de espacios limpios. Precio y disponibilidad con jerarquía visual clara.

### Badges de estado

| Badge | Color |
|-------|-------|
| Producto disponible | Verde `#22C55E` |
| Stock bajo | Amarillo `#FBBF24` |
| Sin stock | Rojo (discreto) |

### Dashboard administrativo

Azul para estructura y navegación. Verde para indicadores positivos. Amarillo para alertas.

## Estilo general

La interfaz debe sentirse:

- Moderna
- Minimalista
- Comercial
- Amigable
- Confiable
- Mobile-first
- Fácil de comprender
- Con espacios en blanco suficientes
- Con bordes ligeramente redondeados
- Con sombras suaves y discretas
- Sin exceso de colores ni elementos decorativos

Evita gradientes innecesarios, saturación excesiva, demasiados colores simultáneos, sombras fuertes o una apariencia demasiado corporativa.
