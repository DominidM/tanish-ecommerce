# 5.13 Plan de Seguridad — TANISH E-Commerce

## Controles Implementados

| Control | Estado | Evidencia | Archivo |
|---|---|---|---|
| Nonces en formularios | IMPLEMENTADO | `check_admin_referer()` en 3 formularios | class-tanish-inventory-admin.php |
| Capabilities por rol | IMPLEMENTADO | `current_user_can('manage_tanish_inventory')` en cada render | class-tanish-inventory-admin.php |
| Sanitización de inputs | IMPLEMENTADO | `absint()`, `sanitize_textarea_field()`, `sanitize_key()` | class-tanish-inventory-admin.php |
| Escaping de outputs | IMPLEMENTADO | `esc_html()`, `esc_url()`, `esc_attr()` | Todos los templates |
| Prepared statements SQL | IMPLEMENTADO | `$wpdb->prepare()` en queries | class-tanish-inventory-database.php |
| MySQL privado | IMPLEMENTADO | Sin port mapping al host | docker-compose.yml |
| .env excluido de Git | IMPLEMENTADO | `.env` en .gitignore | .gitignore |
| ABSPATH check | IMPLEMENTADO | `defined('ABSPATH') || exit;` en todos los PHP | Todos los archivos |
| Sanitización WhatsApp | IMPLEMENTADO | `sanitize_text_field()` + `preg_replace('/\D/')` | class-tanish-whatsapp.php |
| Escaping URLs WhatsApp | IMPLEMENTADO | `esc_url()`, `rawurlencode()` | class-tanish-whatsapp.php, functions.php |

## Controles Preparados

## Controles Bloqueados

| Control | Estado | Recurso faltante | Acción interna |
|---|---|---|---|
| MFA | BLOCKED | Plugin externo | Evaluar WP 2FA u opción similar |
| Backups automáticos | BLOCKED | Cron/systemd en host | Documentar instrucción manual |
| HTTPS activo | BLOCKED | VPS + dominio | Documentar configuración preparada |
| Search Console | BLOCKED | Cuenta Google | Preparar sitemap + robots.txt |

La seguridad implementada cubre los controles básicos para una aplicación WordPress/WooCommerce. Los controles BLOCKED dependen de infraestructura externa. Los NO IMPLEMENTADOS son mejoras futuras no críticas para el MVP académico.
