## Backup

### Estrategia
| Tipo | Frecuencia | Retención | Método |
|---|---|---|---|
| Full DB backup | Diario | 7 días | `scripts/backup.sh` |
| Manual on-demand | Según necesidad | Indefinido | `scripts/backup.sh` |
| Git commits | Continuo | Indefinido | `git push` |

### Ejecución
```bash
# Backup manual
docker exec tanish-mysql mysqldump -u "$DB_USER" -p"$DB_PASSWORD" tanish_wordpress | gzip > backups/tanish_$(date +%Y%m%d-%H%M%S).sql.gz

# Restore
./scripts/restore.sh backups/tanish_backup_YYYYMMDD-HHMMSS.sql.gz
```

## Rollback

| Escenario | Acción |
|---|---|
| Deploy fallido | `git checkout [commit-funcional]` + redeploy |
| BD corrupta | `./scripts/restore.sh [backup]` |
| Plugin conflictivo | Desactivar desde WP Admin o `wp-cli` |
