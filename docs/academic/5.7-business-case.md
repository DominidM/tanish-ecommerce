# 5.7 Business Case — TANISH E-Commerce

## Problema

Tanish S.A.C. gestiona su inventario mediante procedimientos manuales, sin un mecanismo centralizado que permita registrar movimientos de entrada, salida o ajuste que no correspondan a una venta. Esta situación genera el riesgo de que el stock disponible no coincida con las existencias reales.

## Oportunidad

La digitalización del canal de venta mediante WordPress/WooCommerce permite:
- Exhibir el catálogo de productos en línea
- Gestionar precios y stock desde una plataforma centralizada
- Habilitar un canal de venta B2C adicional al presencial
- Registrar movimientos de inventario con trazabilidad completa

## Beneficio

| Beneficio | Descripción |
|---|---|
| Visibilidad digital | Catálogo accesible 24/7 |
| Control de inventario | Trazabilidad de movimientos sin dependencia de pedidos |
| Eficiencia operativa | Reducción de errores manuales en kárdex |
| Canal adicional | Venta B2C + WhatsApp como alternativa |
| Analítica | Medición de comportamiento del comprador digital |

## Alternativa Seleccionada

**WordPress + WooCommerce + Plugin TANISH Inventory**

| Criterio | Justificación |
|---|---|
| Costo | Open source, sin licencias |
| Madurez | WordPress (43% web global), WooCommerce (plugin #1 e-commerce) |
| Flexibilidad | Plugin propio para inventario |
| Comunidad | Soporte amplio, documentación extensa |
| Escalabilidad | Posibilidad futura B2B |
