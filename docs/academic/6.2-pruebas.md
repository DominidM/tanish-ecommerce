## Pruebas Unitarias (Sprint 05)

### Objeto
Validar que el código PHP del plugin no tiene errores de sintaxis ni lógica básica.

### Alcance
- `class-tanish-inventory-service.php`
- `class-tanish-inventory-database.php`
- `class-tanish-inventory-capabilities.php`

### Método
```bash
php -l plugins/tanish-inventory/includes/*.php
```

### Criterio de aceptación
- 0 errores de sintaxis PHP
- Output limpio en todos los archivos

## Smoke Tests (Sprint 05)

### Objeto
Verificar que las páginas principales responden HTTP 200.

### Alcance
| Página | URL | Método |
|---|---|---|
| Home | http://localhost:8080/ | curl -s -o /dev/null -w "%{http_code}" |
| Shop | http://localhost:8080/shop/ | curl -s -o /dev/null -w "%{http_code}" |
| Cart | http://localhost:8080/cart/ | curl -s -o /dev/null -w "%{http_code}" |
| Checkout | http://localhost:8080/checkout/ | curl -s -o /dev/null -w "%{http_code}" |
| My Account | http://localhost:8080/my-account/ | curl -s -o /dev/null -w "%{http_code}" |
| Inventario | http://localhost:8080/wp-admin/admin.php?page=tanish-inventory | curl -s -o /dev/null -w "%{http_code}" |
| Kárdex | http://localhost:8080/wp-admin/admin.php?page=tanish-kardex | curl -s -o /dev/null -w "%{http_code}" |

### Criterio de aceptación
- Todas las páginas responden HTTP 200
- Sin errores 500/404
